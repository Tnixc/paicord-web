# React + Tailwind + Vite+ Starter

A minimal starter built with React, TypeScript, Tailwind CSS v4, and Vite+.

## Stack

- React 19
- TypeScript
- Tailwind CSS v4
- Vite+

## Getting Started

1. Install dependencies:

```bash
vp install
```

2. Start the dev server:

```bash
vp dev
```

3. Run checks:

```bash
vp check
```

4. Run tests:

```bash
vp test
```

## Tailwind Setup

Tailwind CSS v4 is configured using the Vite plugin and CSS-first configuration:

- [vite.config.ts](./vite.config.ts) loads `@tailwindcss/vite`
- [src/index.css](./src/index.css) imports Tailwind with `@import "tailwindcss";`

## Use As A Template

After publishing this repository to GitHub and marking it as a template, you can create new starter projects from it using the "Use this template" button on GitHub.
